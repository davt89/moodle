# Moodle — Flutter Coursework


## Project Description
A Flutter based appliaction that displays a student's modules, assesments, profile information, and course information.


## Prerequisites
Have installed:
Flutter
Dart
VS Code


## Fork and Clone the Repository

Clone the repository using https://github.com/davt89/moodle
Install dependencies by running flutter pub get
Run the application with flutter run
